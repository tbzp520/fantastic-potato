人工复算：把完整的“手工复测”文件夹拷走就能算

每次测试的所有基础数据都在“手工复测”文件夹中，复算代码在其内部“人工复算代码”子文件夹。
复制整个“手工复测”，保持这个内部结构，不要只拷代码。

1. 在安装 Python 3.12 的电脑上，双击“人工复算代码/开始复算.cmd”。
2. 它不需要 SSH、温度仪、网络、管理员权限或额外 Python 库。
3. 在“手工复测”内自动生成“人工复算结果”。打开“复算汇总.csv”和“复算说明与对照.txt”。
4. 重算不会修改原始数据或正式温度模版；再次重算会更新“人工复算结果”中的复算文件。

实际用来重算的三个输入：
- 手工复测/完整基础数据.csv：原始温度和带宽，包含已剔除原值，空格代表没采到或非采样点。
- 手工复测/SMART原始计划点.csv：按原定采样时刻记录的 SMART，用于独立判断前两次异常。
- 手工复测/本次复算条件.json：这次测试时长、类型、采样率、剔除规则、显示位数。
这个 JSON 是本次结果的留档，不是控制下次测试的配置；下次测试仍只修改程序目录的 config.json。

规则直接写在“复算温度.py”，用记事本或 VS Code 能看到：
读写测试：前两次 Composite 与第三次及以后有效 Composite 的均值比较，绝对差 >= 8℃ 时剔除。
默认同一轮 Composite、CPU、NAND 都不参加统计；若原次设置 composite 则只剔除 Composite。
L0、L1.2：不剔除前两次。
最后10分钟：正式测试相对秒 >= 时长-600 且 < 时长；不是按绘图重新归零后的横轴选数。
均值 = 实际有效值之和 / 实际有效值数量。缺值不能按0算，真实0需要算；没有有效值就留空。
原始值始终保留。绘图裁掉前段不代表前段所有传感器原值都被剔除。
v2.2.1 所有曲线统一画到最后有效 SMART 点，之后的数据仍保留并按最后10分钟规则统计。
900秒读写的统计范围是原始第300秒（含）至900秒（不含），不是图中最后600秒。
本次复算条件中的 chart_start_original_second / chart_end_original_second 仅描述绘图范围，不参与统计取数。

与公司温度模版的对应：
Composite → 复合温度；CPU_Surface → CPU表面；NAND_Surface → NAND表面。
最大、平均、最小使用“复算汇总.csv”的对应显示值；原值列保留未舍入的精度。
SMART 的 CPU、NAND 不能替代温度仪的 CPU_Surface、NAND_Surface。

想用 Excel 人工验算：
打开“手工复测/基础数据.xlsx”，查看“参与统计的数据”和“人工复算”工作表。
人工复算页含 COUNT/MAX/AVERAGE/MIN 公式；完整基础数据页没有删除原始异常点。
“基础数据_北京时间.csv”方便按北京时间查找；原始 Time 是带 +00:00 的 UTC，Second 是正式相对秒。
缺秒看“缺失数据时间点.csv”和“先看数据完整性.txt”，不要把空白补0。

对照文件“程序统计结果_仅供对照.json”不参与计算，只在计算完成后比较。
“原始输入校验.json”用于指出原始输入是否被编辑过；编辑过仍可复算，但会明确提示。
若输出存在差异，先检查输入文件是否修改、最后600秒边界和剔除规则，不要覆盖原报告。
