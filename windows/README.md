# Windows 测试端 v0.4.22 登录后全屏修复版

程序分别运行在 Windows 测试主机和接收电脑。接收电脑连接 JK808，通过 FTDI USB NMC 线与测试主机通信；HWiNFO32 使用固定 U 盘，BurnInTest 使用系统盘已有安装，在线视频使用任务栏常用 Edge 的正常用户环境。

## 首次使用与更新

直接使用请下载同版本 `JK808_Windows_v0.4.22_full.zip`。包内提供便携 Python、FTDI 驱动、VC++ 依赖和空模板；HWiNFO32、BurnInTest、Edge 及视频由使用者准备。先核对旁边的 `.zip.sha256`，完整解压后运行 CMD。

首次运行「配置环境.cmd」，选择本机角色。填写自己的项目、批次、测试版本、可访问的 NTP、本地视频文件和在线视频网址。分别运行「开始_测试主机.cmd」「开始_接收电脑.cmd」，两端应显示同一版本。

更新前等测试和回传结束，退出旧窗口，完整解压新版。将每台电脑原 `config.json` 复制到各自新目录，不要互换配置。测试主机每次正式预检自动识别本机平台和系统盘；接收端不以自己的电脑信息冒充被测平台。换机后路径或设备无法唯一识别时，按提示重新定位；不会下载视频或更改 BIOS。

## 测试和登录

整套顺序为在线视频、待机、本地视频、BIT。只有新建整套首项在线视频跳过开始前等待；后续项目、单项、联调和续测保留原等待设置，不把 config 中等待值改成 0。

扫码期间保持普通 Edge 窗口，不限定等待多久，也不计正式测试时间。确认登录后，程序才设置画质、播放、最大化和视频全屏；至少 1080P / 30 帧及播放就绪后开始正式计时。本轮只关闭自己新建的 Edge 测试窗口，其他日常窗口可保留。

B 可直接正式测试；D 保留完成项，只重试原电脑、原 SSD 的未完成项；C 补取原任务；E 重建批次汇总。更换型号、CPU、系统版本或 BIOS 使用新批次。同配置电脑可按盘身份规则汇总，但 D 续测还要求原物理电脑。

原始 SMART 全量记录、JK808 每秒记录、正式段和绘图选点分别提供中文 CSV/HTML。图表和采样详见 [操作指导.html](操作指导.html)。本次登录流程修复仍需结合实际登录、网络及双机设备确认。

## 源码开发

Git 源码不含 runtime、drivers、prerequisites。安装 Python 3.12 x64 和 `requirements.txt` 依赖；CMD 的便携运行环境来自同版本完整附件。首次启动根据 `config.example.json` 创建 `config.json`，实际配置不要提交。

```powershell
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
```

测试包含模拟设备和本地浏览器页面用例；部分浏览器用例需要本机 Edge。不要将测试通过写成现场双机验收通过。源码公开副本使用可替换的公网 NTP 示例，保留用户自定义 NTP，不迁移到固定内网地址。
