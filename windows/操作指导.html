Windows 0.4.12 · 操作指导

2026-10-21。整套执行顺序为：在线视频 → 待机 → 本地视频 → BIT。每项开始前仍等待2分钟。保留网页5次刷新重试、续测、容量命名及SMART配置修复。

1. 更新和连接

  1. 等当前测试及文件回传结束，退出两端旧程序。将完整包解压到新目录，不能在ZIP中运行。测试主机放在固定U盘上；接收电脑放在原来使用的位置。
  2. 把每台电脑旧目录的config.json分别复制到该电脑的新目录。不要交换两端配置。本包不带config.json，不覆盖人工配置；没有旧配置时首次启动按默认配置创建。
  3. 测试主机接HWiNFO U盘、FTDI互连线；接收电脑接FTDI另一端、JK808。测试主机桌面保持可交互，U盘一直插好。
  4. 停止正在记录的旧HWiNFO日志，关闭旧播放器、测试浏览器和BIT。分别启动开始_测试主机.cmd、开始_接收电脑.cmd，按Windows提示授予管理员权限。两端应显示0.4.12 在线视频优先版。
  5. 主机环境配置完成后保持窗口运行；后续在接收端操作。换盘后沿用同一套系统镜像，直接选择B，不要求先跑联调。

缺少的VC/MFC运行库及FTDI驱动会使用包内离线安装程序补齐，再检查实际COM口；正常驱动不重复安装。配置环境.cmd供单独检查使用。安装仍在运行时先等待，提示重启时手动重启后再运行。程序不会自动重启或修改安全策略。

2. 接收端菜单

  • A 可选联调：只在需要排查异常时做四项短测；不作为正式结果，短测不加2分钟等待。
  • B 正式测试：填写项目、批次，回车可沿用。选择整套四项或单项。系统盘型号、容量和序列号自动识别，无需手填，不复用上一张盘的信息。
  • C 补取上次结果：填写旧结果目录，按任务编号补取文件并生成报告，不重跑负载。需保留主机C:\JK808_Windows\jobs和接收端结果目录。
  • D 继续上次未完成测试：回车选择最近正式任务，或粘贴旧结果文件夹路径。先补取和检查已有数据，保留完成项，依次重试失败项及尚未执行的项目。每次重试独立保存到原目录的“手工复测/续测记录”，最终合并为同一份Excel和报告。

例如在线视频、待机已完成，本地视频失败：选择D只执行本地视频和BIT。旧任务已完成的项目保留，剩余项目按新顺序执行。若失败只发生在回传或Excel出表，先补取或关闭Excel重出报告，不重新施加负载。若再次失败，可继续选D。续测会核对原任务项目、批次、容量、型号、序列号；更换盘片应选B。

HWiNFO沿用绑定U盘中的8.34-5870版本；BurnInTest使用系统盘已有安装；首次使用须在config.json填写本地视频路径和在线视频网址。换盘不要求重新做联调；文件确实缺失或当前盘身份不明时，会给出具体原因。请在config.json填写接收电脑能访问的NTP服务器；校时由接收端经USB传给测试主机。

4. 自动操作

  • HWiNFO：自动点击Start、处理已适配的64位兼容提示、关闭System Summary摘要窗口并进入Sensors。直接设置列表选择状态，停用其他监测项，只启用当前系统盘SMART。Sensors内其他组可能仍显示红叉，表示已经停用。设置30/60秒刷新及CSV记录后读回核对，CSV表头正确才开始负载计时。日志自动放到本轮主机任务目录，完成后回传。
  • 本地视频：用系统播放器打开原文件、最大化、播放，程序独立计时20分钟，不再用进度条检测阻止开始。完成后关闭本轮播放器。
  • 在线视频：首次打开页面失败后自动再刷新重试5次（总计最多6次），提前成功就继续；重试期间不计正式测试时间，Ctrl+C可取消。5次仍失败时保存原因，可选D重试本项。HTTP错误页和浏览器网络错误页也会重试。如需登录，程序不限时等待扫码；登录后自动选择至少1080P、30帧的画质并播放、全屏。2K/4K、60帧也接受。正式计时中网络缓冲不暂停计时、不因进度停滞判失败；实际暂停、关闭播放器、退出全屏等另行记录。结束后关闭本轮浏览器。
  • BIT：自动调用已有配置并确认启动提示，检测实际运行证据后计时，结束时核对BIT自身报告并关闭本轮窗口。

无需手动点击HWiNFO、播放器或BIT；扫码登录除外。Sensors配置保存在Windows注册表，换系统盘后本程序按当前盘自动重设，不依赖旧镜像状态。

5. 数据与结束

结果保存在deliveries/项目/批次/容量_北京时间_任务编号。外层是PNG、HTML和Excel；原始数据、配置快照、诊断和复算代码都在“手工复测”里。例如1T盘输出“本次结果_1T.html”“温度汇总_1T.xlsx”“Windows_在线视频_1T.png”。先看按容量命名的“本次结果”HTML；续测报告会列出每项数据来自哪次尝试。旧版本任务续测仍保留原文件夹名，报告文件会加容量，旧版报告移入手工复测。测试版本由人员填入配置或Excel，未填写时不拿固件版本替代。

Drive Temperature/2/3分别对应Composite/SSD主控/NAND；JK808通道1/2/3分别对应主控表面/NAND表面/环境。选取Composite极差最小的连续10/12/20点；JK808按时间对齐，仅按这些点绘图和统计。图片沿用Linux版10×6英寸、300DPI及温度数字标注，Excel图片随单元格改变位置和大小。

结束时程序停止本轮日志、关闭负载、恢复主机原网络状态，生成固定文件副本回传并校验。请等最终结果提示再打包，不能在.partial文件还在写入时发送。原CSV继续增长不会改变已经生成的回传副本。

取消按Ctrl+C并等待收尾；不要提前删除任务目录。HWiNFO收尾失败时保留原始数据和诊断，不能把失败当作通过。测试主机仍需可交互桌面；程序不自动解锁，也不修改锁屏策略。

本版进行离线回归及完整包校验，包括网页超时/错误页、失败续测、文件回传和合并出表。现场双机、真实播放器和实际网络效果仍需实机确认。
