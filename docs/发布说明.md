# 发布说明

## Windows v0.4.22

- 在线视频未确认登录时保持普通 Edge 窗口，扫码等待不限时、不计正式时间；登录后才画质、播放、最大化及视频全屏。
- 使用本机常用 Edge 用户环境；只关闭本轮新建的测试窗口。
- 每次从测试主机读取机型、CPU、系统、BIOS 及盘片身份，接收端只同步主机快照；换机时重新定位本机工具和设备，无法唯一识别时提示。
- 同批次核对平台，D 续测还核对原物理电脑及原 SSD；保留已完成数据，不混用身份。
- 整套顺序仍为在线视频、待机、本地视频、BIT；新建整套首项免开始前等待，其他等待语义不变。
- 在线/本地视频每 5 秒采 SMART，选一段连续完整 600 秒、每 30 秒一个点，共 20 点；BIT 每 5 秒采样及选点，共 120 点；待机保持原规则。

## Linux v2.3.4

- 保留单机并支持一台 Windows、一台八通道 JK808 控制两台 Linux，分别配置 SSH、盘身份、探针和结果，支持独立启动、取消及续测。
- 启动入口检查 Python 3.12 x64、保留失效环境备份及退出信息，管理员启动不因错误解释器立即闪退。
- 读、写正式记录及 fio 均为 900 秒，SMART 每 5 秒记录，最后 600 秒每 30 秒选真实点，共 20 点；L0、L1.2 沿用既有规则。
- L1.2 后仍由测试人员手动关机调整 BIOS。读写 TRIM 仅针对身份已核对、未挂载的专用测试盘。

## 共同数据与公开副本

两端统一六路温度图颜色、实线和尺寸：3000×1800 PNG，Excel 插入同图，不描点、不平滑、不改源值。原始 SMART、JK808 秒级记录与正式段、绘图选点分开显示，中文 CSV 和 HTML 明确计数、缺失及数据来源；历史数据缺失不补造。

公开源码及完整附件使用原仓库的去数据空白三容量模板，不含现场数据或图像。程序动态追加 128G、256G。公开示例不带实际 SSH、仪器/主机/盘身份、网卡或视频路径，NTP 使用可替换的公网示例，并保留用户自定义地址。现场交付目录不作发布脱敏修改。

源码不提交运行库、驱动或 wheels。Windows 完整附件由安全源码加明确指定的 runtime、drivers、prerequisites 构建；Linux 完整附件增加明确指定的 wheelhouse，更新附件不覆盖配置、模板和依赖。三个 ZIP 分别附 SHA256，包内有逐文件 `FILES.sha256`，构建目录另有 `release-manifest.json`。

验证包括公开配置检查、Python 语法、Windows 启动清单及哈希、ZIP CRC、包内逐文件字节和外部 SHA256。具体测试结果以本次发布记录为准；离线回归不等同现场双机验收，本次登录后全屏修复仍需结合实际登录和网络环境确认。

本次公开副本通过 Windows 393 项、Linux 160 项离线回归。历史现场夹具和原始结果不随仓库发布；公开测试使用合成控件与数据，空模板扩容测试在本目录独立完成。
