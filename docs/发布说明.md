# 发布说明

## Windows v0.4.12

- 整套执行顺序为在线视频、待机、本地视频、BIT，每项开始前等待 120 秒。
- 保留自动识别盘片、按容量命名结果、失败流程续测和已完成数据合并。
- 网页首次打开失败后可再刷新 5 次；扫码登录不限时等待。
- 本地视频由程序独立计时；在线视频至少 1080P / 30 帧并全屏播放。
- HWiNFO 保留当前系统盘 SMART，自动处理已适配的启动提示和摘要窗口。

## Linux v2.2.4

- B→3 新增四项单独测试入口：L1.2、L0、1M 写、1M 读。
- 单项完成后只更新对应结果，不改变原连跑流程的进度。
- 读写正式记录和 fio 均为 900 秒。
- 图表截至最后一个有效 SMART 点，Excel 图片适应预留单元格。

## GitHub 发布副本

公开发布副本清除了现场示例配置、历史报表数据和图片。模板保留原来的三个容量工作表、合并区域及样式。
Windows 不再把已经填写的 NTP 地址迁移到某个固定内网地址；首次配置使用可替换的公网示例。
现场已有 config.json 不在更新包内覆盖，原现场交付包也未修改。

本次发布副本通过 Windows 60 项、Linux 121 项离线测试，以及启动清单和 ZIP/文件哈希检查。正式上机仍以实际双机联调结果为准。
